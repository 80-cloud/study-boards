# study-boards

個人での学習を目的としたプロジェクト集です。Spring Boot / React / Rails / Terraform など複数の技術スタックを試しながら、各アプリを独立した学習プロジェクトとして開発しています。

## 📂 プロジェクト一覧

| プロジェクト | 内容 | 主な技術 | 公開 URL |
|---|---|---|---|
| **[term-board](./term-board)** | IT 用語の学習＋面接対策アプリ | React 19 + TypeScript + Vite | [🌐 公開中](https://80-cloud.github.io/study-boards/term-board/) |
| [task-board](./task-board) | タスク管理 Kanban アプリ | Spring Boot + React + PostgreSQL | — |
| [infra](./infra) | AWS デプロイ環境（task-board 用 IaC） | Terraform + AWS 無料枠 | — |

各プロジェクトの詳細は、それぞれの README を参照してください。

## 開発方針

- 各プロジェクトは独立した学習対象として個別に開発しています
- 共通の開発ルールはリポジトリ内に集約しています
- 学習中の不具合・気付きは各プロジェクトの `docs/` に記録しています

## ライセンス・お問い合わせ

- 各プロジェクトのライセンスは個別の README を参照してください
- 不具合・要望は [Issues](https://github.com/80-cloud/study-boards/issues) で受け付けています
