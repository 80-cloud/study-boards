## S-01 クイズ画面（現行）

### レイアウト構成

```
┌───────────────────────────────────────────┐
│ ヘッダー（banner）                           │
│  ┌ IT用語ボード（h1）                         │
│  └ サブタイトル          [分野フィルタ ▼]     │
├───────────────────────────────────────────┤
│ 進捗バー：解答数 / 正答 / 正答率              │
├───────────────────────────────────────────┤
│ 問題カード                                   │
│  分野ラベル（text-sky-700）                   │
│  「○○」の意味は？（h2）                       │
├───────────────────────────────────────────┤
│ 選択肢ボタン ×4（縦並び）                     │
├───────────────────────────────────────────┤
│ ［回答後のみ］解説カード                      │
│  ◯正解!/✕不正解                              │
│  かんたんに言うと： / 正しい意味：            │
│  面接での言い方： / 現場では：                 │
│  ［次の問題 →］                              │
└───────────────────────────────────────────┘
```

### 状態遷移

```
[出題] ──選択肢クリック──▶ [回答済(採点表示)] ──「次の問題」──▶ [出題(別の用語)]
   ▲                                                              │
   └──────────────── 分野フィルタ変更で出題し直し ◀───────────────┘
```

- **出題状態**：選択肢は活性。クリックで回答へ。
- **回答済状態**：選択肢は無効化（二重回答防止）。正解＝緑＋◯／誤答選択＝赤＋✕。解説カードを表示し「次の問題」にフォーカス。
- **エラー/空**：データ読込失敗時はエラーメッセージ、分野に用語が無い場合は案内文（出題は停止しない＝graceful degradation）。

### 要素仕様（アクセシビリティ）

| 要素 | 実装 | a11y配慮 |
|---|---|---|
| 分野フィルタ | `<select>` ＋ `<label htmlFor>` | ラベル関連付け・キーボード操作可 |
| 選択肢 | `<button>` | キーボード操作可・回答後 disabled |
| 正誤表示 | 色＋記号（◯/✕）＋テキスト | **色のみに依存しない**（WCAG AA） |
| 解説領域 | `aria-live="polite"` | 動的更新をスクリーンリーダーへ通知 |
| 文字色 | sky-700 / slate-700 等 | コントラスト比 AA（4.5:1）以上 |

### レスポンシブ
- コンテナ `max-w-2xl` 中央寄せ。ヘッダーは sm 未満で縦積み。
- スマホのスキマ時間利用を主用途とし、タップ領域を十分に確保（py-3 のボタン）。

### 検証実績
- Lighthouse（モバイル）：**Accessibility=100 / Best Practices=100 / SEO=100**、LCP 92ms・CLS 0.00（要件定義書 A-5）。
