# IT用語ボード（term-board）

IT を学び始めた人のための、**用語を覚える＋面接で言える形にする**ための無料の学習アプリです。

スクールや独学で出会った用語を、4択クイズ・暗記カード・辞典の3形式で反復し、面接の想定問答や自己PRの下書きまで一通り扱えます。

## 🌐 すぐに使えます（無料・ログイン不要）

👉 **<https://80-cloud.github.io/study-boards/term-board/>**

URL を開けば、その瞬間から学習を始められます。インストールも会員登録も不要です。

## こんな人に向いています

- エンジニアスクールや職業訓練校で学習中の方
- 独学で IT を学んでいる方
- IT 業界への就職・転職を考えている方
- 面接前に IT 用語を一気に総ざらいしたい方

## できること

| モード | 内容 |
|---|---|
| 4択クイズ | 277語の用語を選択肢から選んで覚える |
| 暗記カード | 苦手な用語を SRS（間隔反復）で定着させる |
| 用語辞典 | カテゴリ・レベル別に用語を読み返せる |
| 面接Q&A | 自己紹介・ガクチカ・短所・技術質問など35問の想定問答と回答の型 |
| 模擬面接 | 1分・3分などのタイマー付きで「言える」を練習 |
| 自己PR下書き | 穴埋め式で自己PR・志望動機の素材を作る |
| 成果物まとめ | 作ったものを STAR で言語化するテンプレ |
| 学習ダッシュボード | 進捗・苦手・連続学習日数・カバレッジを可視化 |

## 💚 安心して使えるポイント

- **完全無料、広告なし、ログインなし**
- **データはあなたのブラウザにのみ保存されます**（外部に送信されません）
- **アカウントもサーバーもありません** — 攻撃や情報漏えいの心配が原理的にない設計
- 端末間の同期はしません（スマホと PC で別の進捗になります）
- スマホ・PC 両対応、ダークモード対応

## 📣 SNS や Discord で共有する

URL をそのまま貼ると、タイトル・説明・サムネイル付きのリンクプレビュー（OGP）が表示されます。

```

```

### 技術スタック

| レイヤ | 採用 |
|---|---|
| フロント | React 19 + Vite + TypeScript + Tailwind CSS v4 |
| 永続化 | localStorage |
| ホスティング | GitHub Pages（GitHub Actions で自動デプロイ） |
| Node | 24 LTS |

### ローカル開発

```bash
nvm use            # .nvmrc により Node 24
npm install
npm run dev        # http://localhost:5176/ で起動
npm run build      # 本番ビルド
npm run test       # 単体テスト
```

### デプロイ

`main` ブランチへ `term-board/**` の変更が入ると、GitHub Actions が自動でビルドし GitHub Pages へ公開されます。
